## 2. 화면 영역별 컴포넌트 상세 명세

### Zone 1: 상단 유틸리티 바
- **도메인 인디케이터**:
  - 좌측 상단에 `mylink.io/@username` 형식의 현재 프로필 식별자 표기.
  - 네온 그린 펄스 인디케이터(`w-1.5 h-1.5 rounded-full bg-[#00FFA3]`)로 활성 상태 표시.
- **QR 코드 버튼**:
  - 터치 시 화면 중앙에 고화질 QR 코드 모달 팝업 렌더링.
  - 오프라인 밋업이나 PC 사용자가 모바일로 스캔할 수 있도록 유도.
- **공유 버튼**:
  - 모바일 환경: `navigator.share()` (Web Share API) 호출을 통해 카카오톡, 메시지, 인스타 DM 등으로 직접 공유.
  - 데스크톱 환경: 클립보드에 프로필 URL 즉시 복사 및 토스트 팝업(`"프로필 링크가 복사되었습니다!"`) 호출.

---

### Zone 2: 프로필 메인 헤더
- **아바타 프로필 (Avatar)**:
  - 규격: `96px × 96px` (원형).
  - 테두리: 치지직 네온 그린(`border-[#00FFA3]`) 글로우 효과(`pulseGlow` 애니메이션).
  - 상태 배지: 아바타 우측 하단에 `LIVE`(빨강 `#E02020`) 또는 `ONLINE`(초록) 뱃지 부착.
- **이름 / 닉네임**:
  - `fontSize: 20px`, `fontWeight: 700`, `color: #FFFFFF`.
  - 우측에 인증 크리에이터 마크 (체크 아이콘) 및 회원 등급 배지(`PRO`).
- **한 줄 소개 (Bio)**:
  - `fontSize: 13px`, `color: #9DA5B6`, `lineHeight: 1.4`.
  - 최대 2줄 이내로 간결하게 표현.

---

### Zone 3: 소셜 아이콘 바 (SNS Bar)
- **배치**: `flex justify-center gap-2.5` 가로 정렬.
- **아이콘 규격**: `36px × 36px` 원형 버튼.
- **지원 서비스**:
  - **GitHub**: 기본 다크 서피스 → 호버 시 네온 그린 반전.
  - **YouTube**: 기본 다크 서피스 → 호버 시 유튜브 레드(`bg-[#E02020]`).
  - **치지직(Chzzk)**: 네온 그린 볼드 이니셜(`CH`) + 딥 그린 서피스.
  - **X (Twitter)**: 모던 미니멀 X 심볼.
  - **Email**: 다이렉트 메일 작성(`mailto:`) 지원.
- **인터랙션**: 호버/터치 시 `scale-110` 확대 및 브랜드 컬러 글로우.

---

### Zone 4: 상단 고정 (PINNED) 미디어 / 하이라이트 카드
- **구분 배지**: 좌측 상단 `📌 PINNED` 네온 배지 고정 노출.
- **우측 통계**: 누적 클릭수(예: `클릭 312회`) 은은하게 표시.
- **미디어 임베드**:
  - YouTube 또는 치지직 영상 16:9 반응형 썸네일 플레이어.
  - 가운데 원형 재생(Play) 버튼 배치.
  - 터치 시 인라인에서 영상이 즉시 재생되거나 타깃 페이지로 이동.

---

### Zone 5: 스마트 버튼 링크 리스트
- **카드 규격**: 세로 패딩 `14px`, 둥글기 `rounded-2xl`, 다크 서피스(`bg-[#202224]`).
- **내부 요소**:
  1. **좌측 아이콘**: `36px × 36px` 스퀘어 라운드 박스 (이모지 또는 서비스 로고).
  2. **텍스트 영역**:
     - 상단: 링크 타이틀 (`font-bold text-white`, 호버 시 네온 그린 강조).
     - 하단: 보조 설명 문구 (`text-xs text-neutral-400`, 1줄 말줄임).
  3. **우측 액션/정보**:
     - 누적 클릭 횟수 (예: `248회`).
     - 우측 화살표 꺾쇠 아이콘 (`ChevronRight`).
- **인터랙션 피드백**:
  - 탭/클릭 시 백그라운드로 Firestore의 `clickCount: increment(1)` 실행.
  - 새 탭에서 즉시 타깃 URL(`window.open`) 이동.

---

### Zone 6: 푸터 & 방문자 통계 (Footer)
- **방문자 PV 카운터 배지**:
  - `누적 프로필 방문수: 1,284 PV`
  - 방문자가 접속할 때마다 실시간으로 누적 증가.
- **브랜드 로고 / 관리자 진입점**:
  - `⚡️ Powered by 마이링크 (MyLink)` 문구 클릭 시 관리자 로그인(`/admin`) 경로로 유도.

## 3. 인터랙션 및 모달 상태 명세

### 1) QR 코드 모달 (`QR Code Modal`)
- 사용자가 상단 QR 버튼 터치 시 전체 화면을 은은한 딤드(`backdrop-blur-sm bg-black/85`) 처리.
- 중앙 카드에 프로필 전용 QR 코드를 큼직하게 노출 (`150px × 150px`).
- [닫기] 버튼 또는 배경 터치 시 페이드아웃 닫힘.

### 2) 토스트 피드백 (`Toast Feedback`)
- 링크 복사 또는 인터랙션 발생 시 하단에서 슬라이드 업 플로팅 캡슐 노출.
- 네온 그린 보더 + 체크 아이콘 + `"프로필 링크가 복사되었습니다!"` 문구.
- 2초 후 자동 소멸.
